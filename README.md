## Overview

Helpful Hotkeys adds a suite of quality-of-life keybinds: quick-trash, quick-equip, potion toggle, wire-mode shortcuts, and inventory sort, all fully rebindable via the vanilla controls menu.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Terraria Helpful Hotkeys** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Quick Trash** | Single key to delete the item under the cursor without dragging |
| **Potion Toggle** | Bind to instantly toggle all buff potions in inventory |
| **Inventory Sort** | Hotkey sorts inventory by item type and stack size |
| **Wire Mode** | Fast-access binds for actuator and wire placement tools |
